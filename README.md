# DashSupport.Team Desk

The Dash DAO Builder Support Team. More Than A DAO Help Desk.

- **Office Hours:** Monday to Friday, 1 to 4 PM Central.
- **Status:** `status.json` says whether August is at the desk right now. The page at https://www.outlier.systems/dashsupport reads it live.
- **Tickets:** open an issue here. Every ticket is public and you can follow it.
- **Dasha:** answers around the clock at https://www.dashsupport.team

Signal (August only, from a terminal with `gh` signed in): `dash-desk on`, `dash-desk off`, `dash-desk on "back at 2:30"`.
